A short poem about agency: the power to stop and to stay. `main.ts` (Node 22) writes the poem to `/output/entry.txt` — twelve short lines built on concrete images (an unopened door, a still-warm chair, a number never dialled, a step not taken), turning on the recognition that stopping is not losing: it is holding the reins and choosing, at last, the field not to cross.

## Run it

```sh
node main.ts
# writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
